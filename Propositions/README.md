# Propositions

Artefacts Claude de type proposition/annonce visuelle liés à Dropit, mais qui ne sont ni de la stratégie de lancement (`Lancement/`) ni du contenu marketing — des decks illustrés d'une fonctionnalité, avec leurs images.

- `icones-urgence.html` → *Icônes d'urgence* — trois pistes de badge visuel pour montrer l'urgence d'une tâche par son échéance.
- `questionnaire-arrivee/index.html` (+ `questionnaire-arrivee/assets/`) → *Le questionnaire d'arrivée* — annonce du questionnaire de personnalisation à l'inscription (20 questions), avec le correctif d'un bug d'affichage. Copie complète avec ses 11 captures d'écran, pour rester consultable hors de claude.ai.
